HOW TO OPEN ON YOUR COMPUTER
1. Download this ZIP and extract/unzip it.
2. Open the extracted folder named vaibhav-portfolio-final in VS Code.
3. In VS Code, open index.html.
4. Right-click inside index.html and choose “Open with Live Server”. If Live Server is not installed, install the “Live Server” extension first.
5. You can also double-click index.html to open it directly in Chrome.

HOW TO PUT IT ONLINE FOR FREE
1. Create/sign in to a GitHub account.
2. Create a new public repository and upload all files/folders from this extracted portfolio folder (keep the assets folder structure).
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. GitHub will provide your public portfolio website link after deployment.
